Detailed Description

This is public structure 'GLdata'. It is used for transferring information to GL functions.

name: GLdata

Parameters
levelis an integer. It holds the depth level of an instance of MDE within another instance of MDE.
indexis an integer. It holds the index of the element within the private member vMDE standard vector of pointer to MDE.
mde_memberis an enum MDE_member{name,data}. It holds the about the nature of the data, name for private member 'name', 'data for public member 'data'.
MDE_datais standard string. it holds the data itself. This is class MDE.
