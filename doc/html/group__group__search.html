This member function is to search an entire Entity recursively all instances that has their name equal to the standard string searchName in parameter. It stores all the results in the static (class) member search_result which is a standard vector of pointers to pointers of MDE. The results of the search can be displayed with method fetch_search_result.

This member function is to part of the recursive algorhythm in the search_for method. It recursively stores pointers to pointer to MDE in the static (class) member search_result when the search is successful. It calls a similar methods called simple_loop_VMDE_next_level in its recursive process to separate scopes of the different sub-entities of an entity.
