This member function is to recursively fill-in a standard vector of struct GLdata by extracting data from public member 'name' and public member 'data', and setting the level and index of each Entities and sub-entities of an instance of object class MDE. The vector of GLdata my_v_MDE_data is used to set offset coordinates for displaying MDE and further up in the pipeline to process other coordinates input like rules and padding. This function has a wrapper init_data(), called from main.cpp without any arguments. The two booleans variables displayDataOnly and hideparents are used as their names clearly state, for an end display of only data, and without the parent MDE. This is typically for HTML rendering.
